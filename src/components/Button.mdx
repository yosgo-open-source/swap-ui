# Button

觸發主要動作的按鈕。以 `variant` 決定視覺層級。用法與原生 MUI Button 相同——
從 `@mui/material/Button` 匯入即可，SWAP 品牌樣式由 theme 自動套用（需在最外層包一層 `SWAPThemeProvider`）。

## 使用時機

- **主要動作**（送出、確認、下一步）→ `variant="primary"`
- **次要動作**（取消、上一步）→ `variant="secondary"`
- **低強度動作**（更多、輔助操作）→ `variant="tertiary"` 或 `variant="text"`
- **危險動作**（刪除、解除綁定）→ `variant="danger"`
- 一個畫面**聚焦一顆 primary**，避免多顆主按鈕分散注意力。

## 基本用法

<Source
  language="tsx"
  code={`import Button from "@mui/material/Button";

<Button variant="primary" onClick={handleSubmit}>
  送出
</Button>`}
/>

## 狀態

`disabled` 轉為灰字＋淡色底（保留 variant 色系身分）；`loading` 顯示 variant 色系的轉圈並鎖住點擊（用 v9 原生 `loading` prop）。兩種狀態滑鼠移入都顯示 🚫（not-allowed）游標。

⚠️ `loading` 請永遠傳布林（`loading={isFetching}`），不要條件展開（`{...(isFetching && { loading: true })}`）——`undefined ↔ true` 切換會重組 loading 的 DOM 結構，遇到 Google 翻譯等會修改 DOM 的瀏覽器擴充功能可能 crash。
