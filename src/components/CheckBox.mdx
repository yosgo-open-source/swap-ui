# CheckBox

核取方塊（24px、品牌藍勾選）。內建 label 排版與 40×40 點擊區。

## 使用時機

- 多選、單一開關同意（條款勾選）。
- 互斥單選用 RadioButton；即時生效的開關用 Switch。
- `labelPlacement` 控制文字位置；密集列表可用 `disableHover` 關閉 hover 底色。

## 基本用法

<Source language="tsx" code={`import { CheckBox } from "@yosgo/swap-ui";

<CheckBox label="同意服務條款" checked={agreed}
  onChange={(e) => setAgreed(e.target.checked)} />`} />
